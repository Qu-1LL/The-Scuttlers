# The Scuttlers

Thanks for playing this in-progress build of The Scuttlers.

## Launch

Unzip the package, then run:

```text
The Scuttlers.exe
```

Keep the `GameFiles` folder next to the launcher. It stores the actual game runtime, textures,
fonts, music, and sound effects.

## Notes

- This Windows package is self-contained, so it should not require a separate .NET install.
- If Windows SmartScreen appears, choose `More info` and then `Run anyway` if you trust this build.
- The settings button in the top-left opens volume controls and a music checkbox.
